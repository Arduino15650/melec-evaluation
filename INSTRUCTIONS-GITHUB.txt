# Version GitHub Pages — MELEC

Le dossier `dist` produit par `npm run build` contient la version statique à publier.

Pour une publication manuelle, utilisez directement le contenu du dossier séparé `MELEC-GITHUB-PAGES-A-PUBLIER` fourni avec ce projet.

> **Base de données APP2 :** ce projet utilise le projet Supabase `zjygvzrdwooldtjovvra` et conserve les clés de cache historiques d'APP2.

Les différentes pages utilisent une navigation par ancre (`#/classes`, `#/eleves`, `#/e2`, etc.), compatible avec GitHub Pages et son hébergement dans un sous-dossier.

## Initialisation et mise à jour Supabase

Cette version ajoute une protection serveur des connexions. Avant de remplacer les fichiers du site sur GitHub, appliquer le script `access-security.sql` au projet Supabase APP2, puis déployer `functions/app-login/index.ts` comme fonction `app-login`. La fonction `functions/security-mail/index.ts` est également nécessaire pour l'envoi des alertes par e-mail. Les détails et les secrets à configurer sont indiqués dans `ACCESS-SECURITY.md`.

Les nouveaux enseignants doivent fournir un code valide puis confirmer leur e-mail.
Leur profil reste en attente (`approved = false`) jusqu'à ce qu'un administrateur
clique sur **Autoriser l'accès** dans **Accès des enseignants**.
Le code d'inscription ne vaut pas autorisation d'accès. Les comptes déjà autorisés
conservent leur statut ; l'administrateur peut utiliser **Suspendre l'accès**.
Après remplacement du mot de passe d'un enseignant, notamment en cas d'oubli,
son compte repasse en attente d'autorisation. Une connexion habituelle ne change
pas cette autorisation. Authenticator reste obligatoire pour accéder aux données,
y compris après récupération. Les comptes administrateurs ne sont pas mis en attente.

Dans le tableau de bord Supabase, ouvrir **SQL Editor**, créer une nouvelle requête,
coller l'intégralité du script ci-dessous puis cliquer sur **Run**.
Ce script est réexécutable et doit aussi être relancé après une mise à jour du site.
Le dépôt GitHub ne peut pas installer les fonctions de la base à lui seul.

create or replace function public.handle_new_user()
returns trigger
language plpgsql
security definer
set search_path = public, extensions
as $$
declare
  requested_access_code text := coalesce(new.raw_user_meta_data ->> 'access_code', '');
  teacher_code_valid boolean := false;
begin
  -- Auth met les métadonnées à jour après l'insertion et à la confirmation.
  -- Le code est à usage unique : ne le vérifier qu'à la création du compte.
  if TG_OP = 'UPDATE' then
    update public.profiles
    set email = lower(coalesce(new.email, '')),
        full_name = coalesce(new.raw_user_meta_data ->> 'full_name', '')
    where id = new.id;
    return new;
  end if;
  if requested_access_code <> '' then
    select exists (
      select 1 from public.teacher_access_codes c
      where c.teacher_email = lower(coalesce(new.email, ''))
        and c.active = true
        and c.used_at is null
        and c.access_code_hash = crypt(requested_access_code, c.access_code_hash)
    ) into teacher_code_valid;
  end if;
  if lower(coalesce(new.email, '')) <> 'aitelhadjmustapha@yahoo.fr'
     and not teacher_code_valid then
    raise exception 'Code d’accès enseignant invalide ou déjà utilisé';
  end if;
  insert into public.profiles (id, email, full_name, role, approved)
  values (
    new.id,
    lower(coalesce(new.email, '')),
    coalesce(new.raw_user_meta_data ->> 'full_name', ''),
    case when lower(coalesce(new.email, '')) = 'aitelhadjmustapha@yahoo.fr'
      then 'admin' else 'teacher' end,
    lower(coalesce(new.email, '')) = 'aitelhadjmustapha@yahoo.fr'
  )
  on conflict (id) do update set
    email = excluded.email,
    full_name = excluded.full_name;
  if teacher_code_valid then
    update public.teacher_access_codes
    set used_by = new.id, used_at = now(), active = false
    where teacher_email = lower(coalesce(new.email, ''));
  end if;
  return new;
end;
$$;

create or replace function public.upsert_teacher_access_code(
  teacher_email text,
  plain_code text,
  teacher_name text
)
returns void
language plpgsql
security definer
set search_path = public, extensions
as $$
begin
  if not public.is_admin() or coalesce(auth.jwt() ->> 'aal', '') <> 'aal2' then
    raise exception 'Double authentification administrateur requise';
  end if;
  insert into public.teacher_access_codes (

    teacher_name = excluded.teacher_name,
    updated_at = now();
end;
$$;

create or replace function public.record_password_reset_request(requested_email text)
returns void
language plpgsql
security definer
set search_path = public, extensions
as $$
begin
  if exists (select 1 from public.profiles where email = lower(trim(requested_email)))
     and not exists (
       select 1 from public.security_events
       where email = lower(trim(requested_email))
         and event_type = 'password_reset_requested'
         and created_at > now() - interval '1 hour'
     ) then
    insert into public.security_events (email, event_type)
    values (lower(trim(requested_email)), 'password_reset_requested');
  end if;
end;
$$;

create or replace function public.request_password_reset(requested_email text)
returns jsonb
language plpgsql
security definer
set search_path = public, extensions
as $$
declare
  normalized_email text := lower(trim(requested_email));
  current_count integer;
  currently_blocked boolean;
  block_after_send boolean;
begin
  -- Réponse neutre pour ne pas révéler l'existence d'un compte.
  if normalized_email = '' or not exists (
    select 1 from public.profiles where email = normalized_email
  ) then
    return jsonb_build_object('allowed', true, 'remaining', 4, 'blocked', false);
  end if;

  insert into public.password_reset_limits (email)
  values (normalized_email)
  on conflict (email) do nothing;

  select request_count, blocked
    into current_count, currently_blocked
  from public.password_reset_limits
  where email = normalized_email
  for update;

  if currently_blocked then
    return jsonb_build_object('allowed', false, 'remaining', 0, 'blocked', true);
  end if;

  current_count := least(current_count + 1, 5);
  block_after_send := current_count >= 5;
  update public.password_reset_limits
  set request_count = current_count,
      blocked = block_after_send,
      updated_at = now()
  where email = normalized_email;

  insert into public.security_events (email, event_type)
  values (normalized_email, 'password_reset_requested');

  if block_after_send and not exists (
    select 1 from public.security_events
    where email = normalized_email
      and event_type = 'password_reset_blocked'
      and read_at is null
  ) then
    insert into public.security_events (email, event_type)
    values (normalized_email, 'password_reset_blocked');
  end if;

  return jsonb_build_object(
    'allowed', true,
    'remaining', 5 - current_count,
    'blocked', block_after_send
  );
end;
$$;

create or replace function public.password_reset_status(requested_email text)
returns jsonb
language sql
security definer
set search_path = public, extensions
as $$
  select jsonb_build_object(
    'blocked', coalesce((
      select blocked from public.password_reset_limits
      where email = lower(trim(requested_email))
    ), false)
  );
$$;

create or replace function public.cancel_password_reset_request(requested_email text)
returns void
language plpgsql
security definer
set search_path = public, extensions
as $$
declare normalized_email text := lower(trim(requested_email));
begin
  -- Annule uniquement la réservation la plus récente lorsque Supabase Auth
  -- refuse réellement l'envoi (temporisation ou quota d'e-mails).
  update public.password_reset_limits
  set request_count = greatest(request_count - 1, 0),
      blocked = false,
      updated_at = now()
  where email = normalized_email;

  delete from public.security_events
  where id = (
    select id from public.security_events
    where email = normalized_email
      and event_type = 'password_reset_requested'
    order by created_at desc
    limit 1
  );

  if coalesce((
    select request_count from public.password_reset_limits
    where email = normalized_email
  ), 0) < 5 then
    delete from public.security_events
    where email = normalized_email
      and event_type = 'password_reset_blocked'
      and read_at is null;
  end if;
end;
$$;

create or replace function public.admin_unlock_password_reset(target_email text)
returns void
language plpgsql
security definer
set search_path = public, extensions
as $$
declare normalized_email text := lower(trim(target_email));
begin
  if not public.is_admin() or coalesce(auth.jwt() ->> 'aal', '') <> 'aal2' then
    raise exception 'Double authentification administrateur requise';
  end if;
  if not exists (select 1 from public.profiles where email = normalized_email) then
    raise exception 'Compte introuvable';
  end if;
  insert into public.password_reset_limits (email, request_count, blocked, updated_at)
  values (normalized_email, 0, false, now())
  on conflict (email) do update set
    request_count = 0, blocked = false, updated_at = now();
  insert into public.security_events (email, event_type)
  values (normalized_email, 'password_reset_unblocked');
end;
$$;

create or replace function public.complete_password_reset()
returns void
language plpgsql
security definer
set search_path = public, extensions
as $$
declare account_email text := lower(coalesce(auth.jwt() ->> 'email', ''));
begin
  if auth.uid() is null or account_email = '' then
    raise exception 'Session de récupération invalide';
  end if;
  insert into public.password_reset_limits (email, request_count, blocked, updated_at)
  values (account_email, 0, false, now())
  on conflict (email) do update set
    request_count = 0, blocked = false, updated_at = now();
end;
$$;

create or replace function public.set_admin_recovery(
  backup_email text,
  recovery_questions text[],
  recovery_answers text[]
)
returns void
language plpgsql
security definer
set search_path = public, extensions
as $$
begin
  if not public.is_admin() or coalesce(auth.jwt() ->> 'aal', '') <> 'aal2' then
    raise exception 'Double authentification administrateur requise';
  end if;
  if cardinality(recovery_questions) <> 3 or cardinality(recovery_answers) <> 3 then
    raise exception 'Trois questions et trois réponses sont obligatoires';
  end if;
  insert into public.admin_recovery (profile_id, backup_email, questions, answer_hashes)
  values (
    auth.uid(), lower(trim(backup_email)), to_jsonb(recovery_questions),
    to_jsonb(array[
      crypt(lower(trim(recovery_answers[1])), gen_salt('bf')),
      crypt(lower(trim(recovery_answers[2])), gen_salt('bf')),
      crypt(lower(trim(recovery_answers[3])), gen_salt('bf'))
    ])
  )
  on conflict (profile_id) do update set
    backup_email = excluded.backup_email,
    questions = excluded.questions,
    answer_hashes = excluded.answer_hashes,
    updated_at = now();
  update public.profiles set recovery_email = lower(trim(backup_email)) where id = auth.uid();
end;
$$;

create or replace function public.begin_app_login(account_email text) returns jsonb
language plpgsql security definer set search_path=public as $$
declare p public.profiles; a public.app_login_attempts; ticket uuid := gen_random_uuid();
begin
 select * into p from public.profiles where email=lower(trim(account_email));
 if not found then return jsonb_build_object('allowed',true); end if;
 if p.login_blocked then return jsonb_build_object('allowed',false,'blocked',true); end if;
 insert into public.app_login_attempts(user_id) values(p.id) on conflict do nothing;
 select * into a from public.app_login_attempts where user_id=p.id for update;
 if a.last_attempt_at > now()-interval '2 seconds' or (a.attempt_id is not null and a.last_attempt_at > now()-interval '30 seconds') then
  return jsonb_build_object('allowed',false,'busy',true);
 end if;
 update public.app_login_attempts set attempt_id=ticket,last_attempt_at=now() where user_id=p.id;
 return jsonb_build_object('allowed',true,'user_id',p.id,'ticket',ticket);
end $$;

create or replace function public.finish_app_login(target_id uuid, ticket uuid, valid_password boolean, new_session uuid default null) returns boolean
language plpgsql security definer set search_path=public as $$
declare a public.app_login_attempts; p public.profiles;
begin
 select * into a from public.app_login_attempts where user_id=target_id for update;
 if not found or a.attempt_id is distinct from ticket then return false; end if;
 select * into p from public.profiles where id=target_id;
 if p.login_blocked then return false; end if;
 if valid_password then
  if not exists(select 1 from auth.sessions where id=new_session and user_id=target_id) then return false; end if;
  update public.app_login_attempts set failures=0,attempt_id=null where user_id=target_id;
  insert into public.app_login_sessions values(new_session,target_id) on conflict do nothing;
  return true;
 end if;
 update public.app_login_attempts set failures=least(failures+1,5),attempt_id=null where user_id=target_id returning * into a;
 insert into public.security_events(email,event_type) values(p.email,'login_failed');
 if a.failures>=5 then
  update public.profiles set login_blocked=true where id=target_id;
  delete from public.app_login_sessions where user_id=target_id;
  insert into public.security_events(email,event_type) values(p.email,'login_blocked');
 end if;
 return false;
end $$;

create or replace function public.admin_issue_access_code(target_email text, display_name text default '') returns jsonb
language plpgsql security definer set search_path=public,extensions as $$

 if not public.is_admin() or coalesce(auth.jwt()->>'aal','')<>'aal2' then raise exception 'Double authentification administrateur requise'; end if;

create or replace function public.admin_access_code_status(target_email text, reveal boolean default false) returns jsonb
language plpgsql security definer set search_path=public as $$
declare c public.teacher_access_codes; state text;
begin
 if not public.is_admin() or coalesce(auth.jwt()->>'aal','')<>'aal2' then raise exception 'Double authentification administrateur requise'; end if;
 select * into c from public.teacher_access_codes where teacher_email=lower(trim(target_email));
 if not found then return jsonb_build_object('status','missing'); end if;
 state:=case when c.used_at is not null then 'used' when c.expires_at<=now() or not c.active then 'expired' when c.used_by is not null then 'reserved' else 'active' end;

## Réglages Supabase obligatoires pour la sécurité renforcée

Après avoir exécuté le script SQL ci-dessus :

1. Dans **Authentication > Multi-Factor Authentication**, laisser l’authentification TOTP activée. Elle est compatible avec Microsoft Authenticator.
2. Dans **Authentication > URL Configuration** du projet APP2, conserver `https://arduino15650.github.io/melec-evaluation/` et `http://127.0.0.1:4173/` dans les URL de redirection autorisées.
3. Dans **Authentication > Audit Logs**, activer l’écriture des journaux d’authentification dans PostgreSQL pour conserver la trace complète des connexions et changements de mot de passe.
4. Chaque administrateur et enseignant devra scanner son QR code lors de la première connexion, puis saisir le code à six chiffres à chaque nouvelle connexion.
5. L’administrateur peut ajouter un deuxième authentificateur depuis **Sécurité du compte**. Cette méthode est recommandée comme moyen de secours en cas de perte du premier téléphone.
6. Dans **Authentication > Providers > Email**, régler **Email OTP Expiration** sur `600` secondes. Ce réglage Supabase fixe réellement la durée de vie des liens de récupération à 10 minutes.
7. Le fournisseur d’e-mail intégré à Supabase est limité à deux e-mails d’authentification par heure pour tout le projet, et deux demandes successives visant le même compte doivent être espacées d’au moins 60 secondes. Pour autoriser cinq envois rapprochés, configurer un SMTP personnalisé dans **Authentication > Emails > SMTP Settings**, puis adapter **Authentication > Rate Limits**. Le site ne comptabilise que les envois effectivement acceptés par Supabase.

Après cinq liens envoyés, le compte est bloqué dans l’application. Une alerte apparaît dans **Sécurité du compte > Alertes de sécurité**. L’administrateur doit utiliser **Débloquer et envoyer un lien** ; le nouveau lien revient vers cette application. En local, ouvrir le lien sur le même ordinateur avec le serveur démarré.

Les questions de contrôle enregistrées pour l’administrateur sont hachées et ne sont jamais affichées. Elles servent uniquement à une vérification de support et ne remplacent ni le lien de réinitialisation envoyé par Supabase, ni le deuxième authentificateur.
